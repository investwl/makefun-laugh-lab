A short funny line answering the prompt. An AI agent drafts several lines, scores them by the brief, and writes
the winner to `/output/entry.txt`. It ships:

> I was doing my job. The sock was doing its job. Only one of us got consumed.

## Run it

```sh
python3 main.py
```
